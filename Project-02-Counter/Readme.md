# Project 02 — Like Counter

**Difficulty:** Easy  
**Technology:** HTML / CSS / JavaScript  
**Time Target:** 8–10 minutes

---

## 📝 Problem Statement

Complete the `increaseLike()` function so that every click on the **Like** button increases `#likeCount` by exactly **1**.

---

## 🎯 Requirements

- Complete the `increaseLike()` function.
- Every **Like** click should increase the count by exactly `1`.
- Read the current number directly from the page.
- Convert the value to a number before performing the addition.
- Update `#likeCount` with the new value.

---

## ⚠️ Constraints

- Do not modify the supplied HTML.
- Do not use a separate global counter variable.
- Use the existing HTML ID: `likeCount`.
- Keep the existing function name and event wiring.
