# Project 01 — Welcome Message Changer

**Difficulty:** Easy  
**Technology:** HTML / CSS / JavaScript  
**Time Target:** 5–8 minutes

---

## 📝 Problem Statement

Complete the `changeMessage()` function so that clicking the **Start** button changes the message from:

> **Welcome Student**

to:

> **Frontend Practice Started!**

---

## 🎯 Requirements

- Complete the `changeMessage()` function in `script.js`.
- Select the heading using its existing `id`.
- Change only the displayed text of the heading.
- Do not modify the supplied HTML.
- Keep the existing:
  - HTML IDs
  - Function names
  - Event wiring
  - CSS

---

### Initial State

When the page opens:
